# SleepDock 验证记录

## 1.1.1 外圈白边修复

删除 SwiftUI 最外层 0.8 点白色描边和原生窗口阴影，SwiftUI 与磨砂层统一使用圆弧裁切。最终原生窗口缓存检查圆角外 1,872 个像素，全部 alpha=0；窗口背景 alpha=0、hasShadow=false。顶部原来发亮的两行像素由 (75,79,80)/(62,66,67) 降至与内部一致的 (41,45,47)，证明外描边已移除。检查期间保留已有窗口高度，宽度仍为390。只测四个角点不足以判断是否有一圈白色描边，后续同时检查整片角外区域与边缘亮度。

## 1.1 窗口更新

固定宽390点，底部拖柄调整高度；紧凑与展开分别记忆。桌面真实拖动已读回544→460→720，宽度始终390，退出重开仍为720。窗口与内容缓存的四角alpha均为0，背景alpha为0、isOpaque=false；原生窗口截图工具会将透明区铺成白色，不能用RGB截图中的白色推断实际不透明。

新增10项窗口尺寸检查，纳入scripts/check.sh；与原75项合计85项，另有8项合盖守护隔离模拟。1.1只变更窗口与透明呈现，电源控制边界仍如下。

验证日期：2026-10-22。环境：Apple Silicon arm64，macOS 26.6.2；使用 macOS 26.5 SDK 构建，部署目标 macOS 14。旧系统版本未做真机验证。

## 检测精度

Codex 使用真实生命周期事件；通用命令使用进程、心跳及退出状态。只有逐项确认正常完成的整批任务才触发完成后休眠。Cindy 可读运行元数据，但不能可靠区分正常结束与中断。DeepSeek Harness、WorkBuddy、Muse、Claude Code 与自选其他 App 没有可靠任务接口时，使用 App／进程运行状态保护。

短任务中断、任务失联、日志未读完、来源未知、前一任务完成同时另一任务中断，都不会当作全部正常完成。真正休眠前保持保活、再次读取任务状态，准备期间发现新任务／未知／中断则取消。

## 待用户主动启用后验收

真实休眠、关屏、锁屏、硬件合盖、管理员授权及开机启动没有在开发过程中实际触发。合盖保持运行涉及系统整体禁眠，需接电并单独授权；退出后恢复原值。守护本身被 SIGKILL 时，需要下次授权恢复或按记录人工恢复。

App 为本地临时签名，未做 Developer ID 公证。当前交付包为 Apple Silicon 版本。
