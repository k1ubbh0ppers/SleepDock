# SleepDock

原生 macOS 桌面磨砂悬浮插件。适用于 Apple Silicon、macOS 14 及以上。本机开发与验收环境为 macOS 26.6.2。

## 打开与关闭

双击 `SleepDock.app`。首次总开关默认关闭。打开总开关后启用所选休眠规则。标题右侧 `−` 隐藏到菜单栏；菜单栏可重新显示；`×` 完全退出插件并释放休眠保护。窗口可拖动，实用设置可关闭置顶或启用紧凑模式。

1.1.1 版窗口宽度固定 390 点。拖动底部横条或窗口底边可调整高度；内容随高度滚动，紧凑与展开模式分别记住高度，退出重开仍保留。窗口四个圆角外完全透明（alpha=0）；移除外轮廓白色描边与窗口阴影，内部保留磨砂。

## 休眠规则

- 跟随系统：只由已启用的 Agent 守护或屏幕常亮规则临时保护。
- 空闲后休眠：键鼠连续无操作达到指定分钟数才请求休眠；Agent 正在运行时暂缓。
- 倒计时休眠：点击“开始倒计时”后计时，期间操作电脑不重置定时；到期保留 60 秒取消窗口。Agent 任务优先；有任务则等待。
- 永不休眠：插件持续运行时阻止系统空闲休眠。屏幕可独立熄灭；可单独开启“屏幕常亮”。此功能不能覆盖合盖、低电量和用户主动休眠等系统行为。
- 立即休眠：15 秒取消窗口。关屏只关闭显示器；锁屏不等于休眠。

时长支持常用值及 1–1440 分钟。低电量保护会释放插件的保活断言；默认阈值 20%。仅接电保护可在拔掉电源时释放保护。

## 合盖

系统默认保留系统策略；外接显示器模式下系统可能继续工作。

“合盖休眠”在插件运行且总开关开启时，检测合盖并主动请求休眠。若系统已先行休眠，插件无需继续处理。监测约 5 秒一次；Agent 守护优先，但普通保活无法阻止硬件合盖策略。

“保持运行”需要每次单独点击、管理员认证及接电。它使用 macOS 未公开的 `disablesleep` 设置，临时禁止**系统整体休眠**，不只是忽略合盖。启用前会解释影响；没有授权不修改系统。接电与散热必须维持，不应将运行中的笔记本放入包中。

root 守护记录原 `SleepDisabled` 值，只恢复这一项，不修改原有休眠方式、网络、电池等设置。退出、停用、拔电、进程消失或 12 秒心跳超时后，通常约 2–15 秒恢复。每次授权使用独立租约，重复启用按顺序处理。普通断言为 30 秒续租，应用失去响应后会到期。

合盖守护若被管理员 `SIGKILL`，单进程无法自行清理；恢复记录保存在 `/Library/Application Support/com.phecda.SleepDock/LidGuard/state`，下次授权启用会先恢复旧值。需人工恢复时先查看记录中的 `original`，由管理员仅恢复该原值；不要使用“恢复全部电源默认值”。

## 六个 Agent 默认勾选

“监控的 Agent App”包含 DeepSeek Harness、Codex、WorkBuddy、Muse、Claude Code、Cindy，默认全部勾选，可取消，选择会保留。自动识别本机已安装与运行状态，也支持“添加其他 App”。Claude Code 同时检查常见 CLI 安装位置。

**检测方式有区别**：

- Codex：读取本机 `.codex/sessions` 的 `task_started`、`task_complete`、`turn_aborted` 元数据，处理并发与子任务继承历史，只提取生命周期字段，不展示或保存聊天正文。只有真实正常完成事件才触发自动休眠。
- Cindy：只读本机任务库中的运行元数据，可识别未结束任务；现有记录无法可靠区分正常完成与中断，因此不产生正常完成事件，也不把任务消失用于触发自动休眠。
- 其他 App：若没有经过验证的任务结束接口，使用保守的“运行状态保护”。App 开着即保持保护，并暂缓自动休眠；App 退出不冒充“任务正常完成”。界面显示检测方式。
- 通用命令：用随附 `sleepdock-run` 包裹真实 Agent 命令；命令运行期间续租，退出码 0 才标正常完成，失败、中断和失联不会触发自动休眠。需要本机 Python 3。示例：

```sh
'/你的路径/SleepDock.app/Contents/Resources/sleepdock-run' --agent claude --name 'Claude Code' -- claude -p '你的任务'
```

菜单中的“通用接入”可复制当前 App 内的正确路径。将示例末尾替换成实际命令；不会自动修改六个工具的配置。选中的 App/CLI 还可能生成没有正常完成事件的运行状态保护任务，使整批自动休眠持续等待。若只监控显式包装的命令，请在开始任务前取消对应 App 的勾选，并从包装示例中省略 `--agent claude`，使用 `--name 'Claude Code CLI' -- claude -p '你的任务'`。不带 `--agent` 的通用任务独立于六款 App 勾选；带来源的包装任务则与对应 App 一起受勾选过滤。完整说明见项目的 `docs/AGENTS.md`。

“任务完成后自动休眠”默认关闭。启用后，插件观察到的整批被监控任务必须逐项收到正常完成事件，才倒计时 60 秒；键鼠操作、新任务、取消任务或任务状态不明都会取消／暂缓。启动插件时发现的历史完成记录不触发休眠。Cindy 或运行状态保护的 App 没有可靠正常终态时，该批任务不自动触发休眠，可使用明确的倒计时功能，或用通用命令接入可运行的 CLI。

## 系统与兼容边界

开机启动使用系统登录项；建议先将 App 放入“应用程序”。若系统要求批准，在系统设置的登录项中允许。锁屏按钮使用运行时可用的系统接口，若系统移除会显示错误，可改用 Control–Command–Q。

本地临时签名，未做 Developer ID 公证。源码与构建脚本随包提供。真实合盖、主动休眠、管理员授权和开机启动需在用户主动启用后验收；开发检查不让正在运行的任务实际休眠。

## 构建和检查

运行 `scripts/build-app.sh` 生成 `build/SleepDock.app`；`scripts/check.sh` 执行策略与任务解析检查。App 支持只读 `--diagnostics`，`--assertion-probe` 仅短暂创建／释放保活断言，不请求休眠。
