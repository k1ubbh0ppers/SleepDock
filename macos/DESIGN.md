# SleepDock 实现与验收

目标：原生 macOS 桌面悬浮插件，透明磨砂，直接控制空闲／定时／永不休眠、Agent 任务保护、合盖行为；所有功能可停用，关闭即释放控制。

实现：SwiftUI + AppKit 悬浮窗和菜单栏；IOKit 临时电源断言，不改系统原有空闲时间。CGEventSource 读取空闲秒数。Codex 仅读取 JSONL 生命周期事件；其他工具使用本地命令 lease。合盖保持运行必须用户单独授权，root watchdog 在插件退出或失联后恢复原设置。

默认：首次启动总开关关闭；任务完成自动休眠关闭；不自动申请管理员权限、不进入实际休眠测试。任务完成自动休眠启用后，全部任务正常完成才开始 60 秒倒计时；键鼠操作、新任务、状态不明、停用总开关取消倒计时。保护不等于阻止用户从系统菜单主动休眠。

功能：电池与供电信息、低电量释放保护、仅接电保护、显示器常亮独立开关、悬浮置顶、紧凑模式、开机启动、关闭屏幕、锁屏、立即休眠（带倒计时与取消）、事件记录、通用命令接入。

文件：Types.swift 定义状态；Policy.swift 纯休眠策略；AgentMonitor.swift 任务生命周期；PowerControl.swift 断言、供电与合盖授权；SleepModel.swift 编排；WidgetView.swift 原生界面；AppMain.swift 窗口菜单栏与诊断入口。

验收：编译和临时签名；策略边界与真实日志解析测试；实际运行并观察电源断言的创建／释放；界面按钮与关闭清理。合盖、真正休眠、管理员授权留待用户主动启用后实机验收，交付说明明确边界。
