# SleepDock 1.1.1 · 跨平台验证

日期：2026-10-22。构建主机：macOS 26.6.2、Apple Silicon；Node 24、Electron 45.0.0。

## 已验证

- 1.1.1 删除外壳白色描边、窗口阴影与 Windows 原生调整边框。Electron 在 Mac 实际启动，检查圆角外368个像素全部alpha=0，外描边0px、阴影none、nativeShadow=false；宽390、调高520、六项默认勾选均保持。Windows/Linux本机原生显示仍需真机确认。
- 82 项 Node 检查通过：28 Agent 解析／安装与进程识别、19 电源接口模拟、16 纯策略、16 控制器、3 并发回归。
- 并发检查覆盖：合盖启用中停用总开关、合盖恢复中退出、同时读取初始状态；另覆盖系统休眠失败时的退出清理。
- 通用 Python 包装器真实运行成功命令，记录 complete；真实中断命令，记录 aborted。仅使用隔离目录，未触发休眠。
- Electron 页面在 macOS 实际启动；总开关关闭、六项选中、内容宽390、窗口高度调整到520、最小／最大宽均390。退出无未处理异常。
- 原始页面 PNG 为 RGBA，四角 alpha 均为0；HTML与body背景透明。
- 使用 npm 发布的 Electron 45 校验值验证下载运行时，再打包 Windows x64 与 Linux x64。下载镜像提供二进制，SHA256 与 npm 包内校验值匹配。
- 包内包含实际 PE32+ x86-64 Windows GUI 程序与 ELF64 x86-64 Linux 程序，并附平台 helper、完整资源及使用说明。

## 验证边界

本机没有可用的 Windows／Linux 图形测试环境；没有将两个平台的电源行为写成真机通过。PowerShell helper 已人工核查固定参数、原值恢复与脚本调用；未通过真实 Windows PowerShell 执行确认。Linux 原生电源调用使用模拟 runner 与隔离传感器目录验证。

真实 Windows/Linux 首次启动、系统库兼容、任务路径识别、合盖、休眠、锁屏、熄屏、平台权限与异常恢复仍需在目标系统验收。Linux 透明／背景模糊及托盘显示取决于桌面合成器和桌面环境。Windows/Linux 包未做商业代码签名。

## 复用

`npm test` 运行检查，`npm run package` 构建两个 x64 包。`DESIGN.md` 说明模块边界；`resources` 内为平台 helper 与通用接入。日志与测试临时数据不随源码包分发。
