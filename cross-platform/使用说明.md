# SleepDock 1.1.1 · Windows / Linux

## 打开与退出

Windows x64：完整解压运行包，双击其中的 `SleepDock.exe`。保留同目录所有 DLL、resources 和其他文件，不要只复制 exe。应用未做商业代码签名。

Linux x64：解压 tar.gz，双击 `启动SleepDock.sh`，或在终端执行 `./启动SleepDock.sh`。包内含运行时，不要求另装 Node.js。面向有图形桌面的 glibc x64 Linux；依赖桌面常见的 GTK、NSS、X11/Wayland 运行库，发行版兼容性仍需真机验证。没有 systemd/logind 会话时，对应系统动作禁用。程序保留 Chromium 沙箱；不会自动关闭沙箱或修改系统安全配置。

首次总开关关闭；在插件中开启。`−` 隐藏到托盘，`×` 退出并释放保护。某些 Linux 桌面需托盘扩展才能显示托盘图标；隐藏后也可重新启动同一程序找回窗口。

## 窗口与外观

宽度固定 390；拖动底部横条或窗口底边调整高度。选中底部横条后也可用上下方向键每次调整 20。内容自动滚动，紧凑与展开各自记住高度，重开保持。1.1.1 删除外轮廓白色描边、窗口阴影与 Windows 原生调整边框，圆角外完全透明（alpha=0）；窗口内部保留深色半透明层。Windows 11 在系统支持时使用 acrylic；Linux 背景模糊由桌面合成器决定，不能保证所有桌面都有原生磨砂。

## 休眠控制

- 跟随系统：仅启用所选的任务保护或屏幕常亮。
- 空闲后休眠：键鼠空闲达到 1–1440 分钟后，给出 15 秒取消窗口。
- 倒计时休眠：选择时长并点开始，到期给出 60 秒取消窗口；电脑操作不重置普通定时。所选 Agent 工作时等待。
- 永不休眠：运行期间临时阻止系统空闲休眠，不改变系统原有空闲时长。
- 立即休眠：15 秒取消窗口；熄屏、锁屏为独立操作。缺少系统接口时按钮禁用或显示具体失败原因。

低电量默认 20% 时释放保护；可调至 0–50%。仅接电模式在未确认接电时释放保护。屏幕常亮独立开关；窗口置顶、紧凑模式、磨砂深度在实用设置中。

普通空闲保护无法保证覆盖硬件合盖、低电量、系统强制或用户主动休眠。

## 合盖规则

选择系统默认，交回系统原行为。每次启用其他模式前需打开总开关并在应用内确认；保持运行还需接电。合盖模式不跨应用重启自动恢复启用。

Windows：临时修改**当前电源方案的 AC/DC 合盖动作**。保持运行为“不采取任何操作”，合盖休眠为“睡眠”。独立守护先保存原 AC/DC 值并读回确认；停用、退出、父进程结束、心跳失联或保持运行时拔电，会恢复原值。权限不足直接报错，不自动提权。守护本身被强杀时，下次启动先按保存记录恢复；若失败，界面显示记录目录与错误。硬件合盖休眠可能先于 Agent 检测执行；要合盖跑任务请选择保持运行。

Linux：保持运行使用 logind 临时合盖抑制器，不写系统配置；退出释放。某些桌面管理器持有合盖控制，可能覆盖此行为。合盖休眠需读到 ACPI/UPower 传感器：插件检测合盖后，在未受 Agent 保护时发起带取消窗口的系统休眠；系统原策略也可能先执行。Wayland 没有统一熄屏接口时禁用熄屏按钮。

保持运行时请维持接电与散热，不要把运行中的笔记本放入包中。

## Agent 勾选与完成检测

DeepSeek Harness、Codex、WorkBuddy、Muse、Claude Code、Cindy 六项默认全部勾选。显示常见安装路径与运行状态；可取消并保存选择，也可添加本机其他程序。未发现安装的工具保留勾选，方便以后安装。

Codex 读取 `CODEX_HOME/sessions`，未设置时读取 `~/.codex/sessions` 的生命周期字段；不保存聊天正文。其他五款在这些平台未接可靠任务接口，采用保守的进程运行保护：App 打开时保护，App 退出不冒充任务正常完成。GUI 安装和进程命名存在版本差异；未识别的软件可手动添加。跨平台版 Cindy 当前按运行状态保护，精度与 macOS 元数据接入不同。

“完成后自动休眠”默认关闭。开启后，插件观察到的整批任务必须逐项收到正常完成事件才启动 60 秒倒计时；键鼠活动、新任务、中断、失联、未知状态取消休眠。历史完成事件不触发。无法确认正常完成的 App 不触发此功能，可改用明确倒计时或通用命令接入。

通用接入需要本机 Python 3。在插件内点“复制通用命令接入示例”，将结尾换成真实命令。包装器写入 `~/.sleepdock/tasks` 心跳，退出码 0 且未中断才记为正常完成。示例：

```text
Windows: py -3 "实际路径\resources\app\resources\sleepdock-run.py" --agent claude -- claude -p "任务内容"
Linux:   python3 '/实际路径/resources/app/resources/sleepdock-run.py' --agent claude -- claude -p '任务内容'
```

选中的 App/CLI 可能同时生成运行状态保护任务；该任务没有正常完成事件，会阻止整批自动休眠。若只监控显式包装的命令，请在任务开始前取消对应 App 的勾选，并从复制的示例中删除 `--agent claude`，保留后面的 `-- claude ...`。不带 `--agent` 的通用任务独立于六款 App 勾选，仍受总开关与 Agent 保护开关控制；带来源的包装任务则与对应 App 一起受勾选过滤。详见项目的 `docs/AGENTS.md`。

## 验证与源码

运行包已在 macOS 交叉打包，并检查 Windows PE / Linux ELF 入口、资源与归档。跨平台策略、生命周期、电源模拟检查及 Electron 页面实际启动通过。当前没有 Windows/Linux 真机验收；PowerShell 仍需真实 Windows 执行确认，合盖、休眠、锁屏效果不能以模拟替代。完整记录见随包验证记录。

源码目录执行 `npm install`，`npm test` 检查，`npm start` 下载当前主机 Electron 运行时并启动；`npm run package` 构建 Windows/Linux x64。Node.js 需满足依赖要求，当前使用 Node 24。电源 helper 与 UI 均随源码提供。
